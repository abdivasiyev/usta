Everything a review needs, nothing it waits for.

Written in Haskell with GTK 4, usta opens in a blink and keeps your forges in a local cache, so the pages you know are already there.

One inbox, every forge

Review requests, mentions and failed checks from GitHub and Forgejo in one list, with desktop notifications when something needs you.

Reviews on real git diffs

Diffs come from a local mirror: split or unified, changed words marked, comments on any line or range, and files you viewed stay viewed until they change.

Offline first, live when online

Everything synced is kept on disk. Open conversations update as people write, without reloading the page you are reading.

Checks you can act on

Live job logs with colors and folded groups. Run a workflow with its inputs, re-run failed jobs or cancel a run, from the pull request itself.

Forks, clones, new repositories

Fork in a click, open pull requests from your fork, clone into any folder, or start a repository on any forge you use.

Made for the keyboard

⌘K finds any pull request, issue or repository. j and k move, Enter opens, e marks done; text fields know the Emacs keys.

Your links open here

Make usta the default browser and forge links from chat or mail open in the app; every other link goes on to the browser you choose.

Declarative with Nix

A Home Manager, NixOS and nix-darwin module sets every preference from your configuration, so each machine starts the same.

Read the change, not the page around it.

Side by side or unified, with the file's header kept at the top of a long diff and its Viewed box always in reach. Threads sit on their lines; resolved ones fold away.

Install

usta is in beta. It runs on macOS and Linux and checks once a day whether a newer release is out.

macOS

Download usta.dmg from the latest release and drag usta into Applications.

Download usta.dmg →

Linux

Download usta-x86_64.AppImage, make it executable and run it, or install the package for your system.

AppImage → .deb → .rpm →

Nix

Run it at once, or add the Home Manager module and set it up in your configuration.

inputs.usta.url = "github:abdivasiyev/usta";

imports = [ inputs.usta.homeManagerModules.default ];
programs.usta = {
  enable = true;
  settings.theme = "system";
};
